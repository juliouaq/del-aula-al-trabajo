# Del aula al trabajo

Muestra de los sitios web del Proyecto Integrador de **Andragogía** — Licenciatura en Psicología, Área del Trabajo, Facultad de Psicología y Educación, Universidad Autónoma de Querétaro (campus San Juan del Río).

- `index.html`: galería de proyectos agrupados por necesidad formativa.
- `proyectos/`: sitios interactivos de los equipos publicados dentro de la muestra.

Para agregar o editar un proyecto, modifica la lista `DATA` dentro de `index.html`.
